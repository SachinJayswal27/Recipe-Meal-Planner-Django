\# Recipe \& Meal Planner Web Application



A web-based Recipe and Meal Planning application built with \*\*Python\*\* and \*\*Django\*\*. It enables users to browse, create, and organize recipes, as well as schedule daily and weekly meals.



\## Features

\- \*\*Recipe Management:\*\* Manage recipes with ingredients, preparation steps, cooking times, categories, and servings.

\- \*\*Meal Scheduling:\*\* Assign recipes to specific dates and meal slots (Breakfast, Lunch, Dinner, Snack).

\- \*\*Categorization:\*\* Filter recipes across standard meal categories.

\- \*\*Django Admin Interface:\*\* Full administrative panel to manage recipes and meal schedules.



\## Tech Stack

\- \*\*Backend:\*\* Python, Django

\- \*\*Database:\*\* SQLite3

\- \*\*Version Control:\*\* Git, GitHub
